    安装说明

    插件以独立 .bundle 分发，安装时校验签名与指纹
    1. 01
      下载并解压

      点击插件「获取」下载 ZIP 并解压，得到 .bundle 文件。

    2. 02
      信任签名或开启开发者模式

      团队签名插件可在「安全」中信任 Team ID；临时签名插件需开启「开发者模式」。

    3. 03
      导入 RemoteFlow

      在「浮动菜单设置」中点「安装插件」导入 .bundle，呼出灵动岛即生效。

    开发者提交

    将你的插件上架到插件商店

    采用「仓库直连 + 哈希锁定」模式：二进制由你的 GitHub Release 托管，商店索引记录版本、下载链接与 SHA-256 校验值。

    1. 1. 按 SDK 打包并发布 Release

      使用 Plugin SDK 编译 .bundle，签名后打包为 ZIP 上传至你的 GitHub 仓库 Release，并生成 shasum -a 256。

    2. 2. 准备插件清单条目（JSON） 
      {
  "id": "com.yourname.my-plugin",
  "name": "你的插件名称",
  "tagline": "一句话介绍核心功能",
  "category": "productivity",
  "author": "你的名称",
  "repoUrl": "https://github.com/you/my-plugin",
  "version": "1.0.0",
  "downloadUrl": "https://github.com/you/my-plugin/releases/download/v1.0.0/MyPlugin-1.0.0-macos-arm64.zip",
  "sha256": "<ZIP 的 SHA-256>",
  "signing": { "type": "developer-id", "teamId": "YOURTEAMID" }
}
    3. 3. 提交审核

      通过 GitHub Issue 或 Pull Request 提交上述条目；审核通过并核对 SHA-256 后自动收录上线，高质量插件将入选「精选插件」。

    前往 GitHub 提交插件 ↗ 阅读 Plugin SDK
