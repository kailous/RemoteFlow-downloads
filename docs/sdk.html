快速开始

一条命令编译示例插件。

下载解压 SDK 后，直接运行 RichCards 示例构建脚本，导入 RemoteFlow 即可在灵动岛中看到完整卡片与设置面板。

RichCards

ABI 2 · 推荐起点

完整 ABI 2 原生卡片示例：音乐卡片（封面、播放控制、音量滑块、动态撑开列表）+ 图片卡片 + 统一设置菜单。

zsh PluginSDK/Examples/RichCards/build.sh /private/tmp/RichCards.bundle

HelloMenu

ABI 1 · 兼容参考

ABI 1 快捷菜单示例：演示最小 C 导出入口与动态菜单项，适合纯命令型快捷操作。

zsh PluginSDK/Examples/HelloMenu/build.sh /private/tmp/HelloMenu.bundle
